# bcs-master.androidBCS Master

Complete Bangladesh Civil Service (BCS) Preparation Android App

BCS Master is a native Android application designed to help candidates prepare for Bangladesh Civil Service examinations.

Features

- Subject-wise MCQ practice
- Previous BCS question bank
- Daily model tests
- Timed examination system
- Wrong answer tracking
- English vocabulary learning
- Bengali grammar practice
- Personal study progress
- Offline learning support
- Performance analytics

Technology Stack

- Language: Kotlin
- UI: Jetpack Compose
- Architecture: MVVM
- Database: Room
- Navigation: Navigation Compose
- Dependency Injection: Hilt
